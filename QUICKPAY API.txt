RECHARGE REQUEST
HTTP Method : GET / POST

API URL
http://secure.quickpay.lk/api/?action=recharge&format={RF}&mid={Merchant-ID}& provider={Provider-Code}&number={Mobile/DTH-Number}&amount={Recharge-Amount}&refno={Your-Reference-Number}&rurl={Triggering-URL-To-Get-Auto-Response} &hash={Hash-Value}&value1={Value- 1}&value2={Value-2}&value3={Value-3}

CLOUD MACHINE
http://secure.quickpay.lk/api/?action=recharge&mid={Merchant-ID}&secretkey={SecretKey}&provider={Provider-Code}&number=[MOB]&amount=[AMT]&refno=[TID]&format=cloud

Parameters	Data TypeData Type	Required / Optional	Description
mid	String	Required	Merchant ID
number	String	Required	Service Request Account Number
amount	Decimal	Required	Recharge / Bill Amount
provider	String	Required	Provider Code
hash	String	Required	mid|number|provider|amount|refno|rurl|secretkey
refno	String	Optional	Merchant Reference Number
rurl	String	Optional	Triggering URL To Get Auto Response
value1	String	Optional	Additional Values of Landline/EB/Gas/Insurance
value2	String	Optional	Additional Values of Landline/EB/Gas/Insurance
value3	String	Optional	Additional Values of Landline/EB/Gas/Insurance
format	String	Optional	JSON / XML (XML is Default)

Output Example

JSON
{"RechargeStatus":{"reason":"Accepted","reasoncode":"000","rid":1785767,"refno":"325485d47"}}

XML
<?xml version="1.0" encoding="utf-8"?>
<Recharge-Status>
<Status rid="" refno="TEST-112345" reason=" Accepted " reasoncode="000"></Status>
</Recharge-Status>









RECHARGE RESPONSE

Auto Response to Return/Triggering URL
Response

Parameter	Values
rid	Recharge Request ID
refno	Reference Number
number	Service Request Account Number
amount	Recharge Value
status	Recharge Status ( Success / Failure )
transid	Transaction ID
reason	Reason for Failure
hash	mid|rid|txnid|number|amount|status|transid|secretkey
status	Pending / Success / Failure

Output Example
DEFAULT PARAMETERS ON RETURN URL

http://secure.quickpay.lk?rid={Recharge-Request-ID}&refno={Your-Reference- Number}&number={Mobile-Number}&amount={Amount}&status={Status-SUCCESS/FAILURE}&transid={Transaction-ID}&reason={Reason-If-Any}&hash={Secure-Hash-Value}
SET YOUR OWN PARAMETERS ON RETURN/RESPONSE URL
Use the following formats in your Return URL (rurl) or in Response URL (Dashboard->Setting->Preference) to receive values with your own parameters.
Format	Description
{Recharge-Request-ID}	Recharge Gateway Request ID
{Your-Reference-Number}	Your Recharge Request Reference Number
{Mobile-Number}	Mobile/Account Number
{Amount}	Bill/Recharge Amount
{Status}	Status of Recharge in Proper case [Ex. Success / Failure]
{status}	Status of Recharge in lowercase [Ex. success / failure]
{STATUS}	Status of Recharge in Uppercase [Ex. SUCCESS / FAILURE]
{s}	Status of Recharge in Single Letter lowercase [Ex. s / f]
{S}	Status of Recharge in Single Letter Uppercase [Ex. S / F]
{Transaction-ID}	Successful Recharge Transaction ID
{Reason-If-Any}	Reason / Comments If Any
{Secure-Hash-Value}	Secure Hash Value for Secure Transaction
Note, rurl values will overwrite preset Response Url for the particular transaction.

API URL
http://secure.quickpay.lk/api/?action= rechargestatus&format={RF}&mid={Merchant-ID}&hash={Secure-Hash-Value}&rid={Recharge-Request-ID}

OR

API URL
http://secure.quickpay.lk/api/?action= rechargestatus&format={RF}&mid={Merchant-ID}&hash={Hash-Value}&refno={Your-Reference-Number}

CLOUD MACHINE
http://secure.quickpay.lk/api/?action=status&mid={Merchant-ID}&secretkey={SecretKet}&refno=[TID]&format=cloud&[CLOUD]

mid	String	Required	Merchant ID
rid / refno	String	Required	Recharge Request ID / Reference Number
